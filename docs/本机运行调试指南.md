# 本机运行调试指南

Windows 本地开发速查。生产部署见 [调试与部署.md](./调试与部署.md)。

## 环境要求

| 组件 | 版本 / 路径 |
|------|-------------|
| JDK | 17，`C:\Program Files\Microsoft\jdk-17.0.19.10-hotspot` |
| Android SDK | `C:\Users\xiaoyu\AppData\Local\Android\Sdk` |
| 模拟器 | `Yuyue_API35`（API 35，x86_64） |
| Gradle | 项目自带 Wrapper 8.9，无需单独安装 |

项目已配置 `local.properties`（SDK 路径）和 `gradle.properties`（JDK 路径）。

## 启动命令

所有命令在项目根目录 `C:\File\Project\NoteBook` 执行。

### 后端

首次使用：复制 `config.local.properties.example` 为 `config.local.properties`，按需填写（尤其 `LLM_API_KEY`）。该文件不会提交到 Git。

```powershell
cd C:\File\Project\NoteBook
copy config.local.properties.example config.local.properties   # 仅首次

.\gradlew.bat :server:run
```

启动时会打印配置来源，例如 `[Yuyue] Config: ...\config.local.properties`。环境变量同名项会覆盖文件中的值。

验证：

```powershell
curl http://127.0.0.1:8080/health
# 期望：{"ok":true,"app":"语曰 Yuyue"}
```

> 关闭运行后端的终端窗口，服务即停止。App 联调前必须先启动后端。

也可在 Android Studio 中运行 `server` 模块（主类 `com.yuyue.server.ApplicationKt`）。

### 模拟器

```powershell
emulator -avd Yuyue_API35
adb devices   # 应显示 emulator-5554 device
```

若 Device Manager 无可用镜像，安装：

```powershell
sdkmanager "system-images;android-35;google_apis;x86_64"
avdmanager create avd -n Yuyue_API35 -k "system-images;android-35;google_apis;x86_64" -d "Nexus 5X" --force
```

### Android Studio 安装「语曰」

安装前确认：**后端已启动**（见上方命令），否则 App 登录会失败。

#### 第一步：打开项目

1. 启动 Android Studio
2. 选 **Open**，打开 `C:\File\Project\NoteBook`（项目根目录，不是 `android-app` 子目录）
3. 等待右下角 **Gradle Sync** 完成（首次可能较慢）

若 Sync 失败：Settings → Build, Execution, Deployment → Build Tools → Gradle → **Gradle JDK** 选 Microsoft JDK 17。

#### 第二步：选择运行模块

顶部工具栏运行配置下拉框：

- 选 **`android-app`**（不要选 `server`，那是后端）
- 若只有 `server` 或没有配置：点 **Edit Configurations** → **+** → **Android App** → Module 选 `android-app` → OK

#### 第三步：选择设备

设备下拉框（运行按钮左侧）：

| 方式 | 操作 |
|------|------|
| **真机** | USB 连手机 → 开 USB 调试 → 选手机型号（如小米 MIX 3） |
| **模拟器** | Device Manager 启动 `Yuyue_API35` → 选该模拟器 |

不能选 `No Devices`。终端验证真机：

```powershell
adb devices
# 应显示 xxxxx    device
```

#### 第四步：安装并运行

1. 点击绿色 **Run** 按钮（或 Shift+F10）
2. 等待底部 Build 完成，控制台出现 `Installing APK` / `Installed on`
3. 手机自动打开「语曰」；若未自动打开，在应用抽屉搜索 **语曰**

首次在小米手机上安装，开发者选项里还需打开 **USB 安装**，手机上弹出提示时点允许。

#### 第五步：登录使用

1. 输入 11 位手机号，发送验证码
2. 验证码在**电脑后端控制台**或接口 `devCode` 中查看（开发模式）
3. 登录后即可使用

#### 重新安装 / 更新 App

改代码后再次点 **Run** 即可覆盖安装。改了 `API_BASE_URL` 或 Gradle 配置后，先 **Sync Project with Gradle Files** 再 Run。

**命令行等价操作**（不经过 Android Studio UI）：

```powershell
.\gradlew.bat :android-app:installDebug
```

App 包名 `com.yuyue.app`，显示名「语曰」。

### 真机 USB 调试（小米等）

当前 `API_BASE_URL` 已配置为 `http://192.168.5.36:8080`（本机局域网 IP）。

1. **设置 → 我的设备 → 全部参数** → 连点 **MIUI 版本** 7 次 → 开启开发者选项
2. **设置 → 更多设置 → 开发者选项** → 打开 **USB 调试**、**USB 安装**、**USB 调试（安全设置）**
3. 若 **USB 安装** 灰色或无法开启：登录小米账号；部分机型/系统版本要求**插入 SIM 卡**后才能开
3. USB 连接电脑，通知栏选 **文件传输 (MTP)**，允许 USB 调试
4. 手机与电脑连**同一 WiFi**
5. 手机浏览器访问 `http://192.168.5.36:8080/health` 应能打开
6. 按上方「Android Studio 安装语曰」步骤 Run

若手机访问不了 health，在 Windows 防火墙放行 TCP **8080** 入站。

电脑 IP 变化后，改 `android-app/build.gradle.kts` 中 `API_BASE_URL`，Sync 后重新 Run。

### API 地址

| 场景 | 地址 | 配置位置 |
|------|------|----------|
| **真机（当前默认）** | `http://192.168.5.36:8080` | `android-app/build.gradle.kts` |
| 模拟器 | `http://10.0.2.2:8080` | 切回模拟器时改此处 |

## 语音输入（长按语音球）

语曰**不配置云端语音 API**，使用 Android **系统语音识别**（`SpeechRecognizer`）。需在手机上准备：

| 检查项 | 操作 |
|--------|------|
| 麦克风权限 | **设置 → 应用 → 语曰 → 权限 → 麦克风 → 允许** |
| 系统语音引擎 | 小米 MIX 3 若无 Google 服务，需安装语音引擎，如 **讯飞语音+**、**百度语音** 或系统自带语音服务 |
| 网络 | 部分机型系统 STT 需联网 |
| 降级方案 | 点按语音球下方文字 **「点按文字」** 可改用键盘输入 |

长按后应弹出底部输入框并显示「正在聆听…」。松开后出现转写文字；若无文字，查看底部 Snackbar 错误提示。

## 修改后如何生效

| 修改内容 | 操作 |
|----------|------|
| 后端 Kotlin 代码 | 停服务 → 重新 `.\gradlew.bat :server:run` |
| Compose UI 小改动 | Android Studio **Apply Changes**（闪电图标） |
| Android 业务逻辑 | 重新 **Run** |
| `build.gradle.kts` / Manifest / `API_BASE_URL` / Room 表 | Sync Gradle → 重新安装 App |
| 环境变量 | 重启对应进程；用户级变量需重开终端 |

## 常见问题

| 现象 | 处理 |
|------|------|
| `curl` 连不上 8080 | 后端未启动，执行上方启动命令 |
| 浏览器打开 `/` 是 JSON 不是页面 | 正常，这是 API 服务不是网站 |
| `No target device found` | 先启动模拟器或 USB 连接真机并 `adb devices` 有设备 |
| `Error running 'android-app'` | 运行配置选 `android-app`，不要选 `server` |
| `INSTALL_FAILED_USER_RESTRICTED` | 开发者选项打开 **USB 安装**；小米常需登录小米账号，部分 MIUI 还需插 SIM 卡才能开启 |
| 安装失败 / 小米无法安装 | 开发者选项打开 **USB 安装**、**USB 调试（安全设置）**，手机上点允许 |
| `adb devices` 为空 | 开 USB 调试、换数据线/接口、手机上点允许 |
| 桌面找不到 App | 应用抽屉搜索「语曰」，包名 `com.yuyue.app` |
| 真机连不上 API | 同 WiFi、防火墙放行 8080、手机浏览器测 health |
| 无可用系统镜像 | 执行上方 `sdkmanager` 安装命令 |
| Gradle Sync 报找不到 JDK 17 | Settings → Gradle → Gradle JDK 选 Microsoft JDK 17 |
| App 连不上后端 | 确认后端已启动、`API_BASE_URL` 正确 |
| 验证码错误 | 用最新 `devCode`，5 分钟内有效 |
