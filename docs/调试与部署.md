# 生产部署指南

本地开发见 [本机运行调试指南.md](./本机运行调试指南.md)。

## 架构

```text
[Android App] --HTTPS--> [Nginx] --HTTP--> [Ktor :8080] --> [PostgreSQL RDS]
```

## 构建

```bash
gradlew.bat :server:installDist   # Windows
./gradlew :server:installDist    # Linux
```

产物：`server/build/install/server/`

## 服务器配置

环境文件 `/opt/yuyue/server.env`：

```bash
PORT=8080
DEV_MODE=false
JWT_SECRET=<随机长字符串，至少32字符>
DATABASE_URL=jdbc:postgresql://<RDS内网地址>:5432/yuyue
DATABASE_USER=yuyue
DATABASE_PASSWORD=<强密码>
LLM_API_KEY=<大模型Key>
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

systemd 守护进程 `/etc/systemd/system/yuyue.service`：

```ini
[Unit]
Description=Yuyue API Server
After=network.target

[Service]
Type=simple
User=yuyue
WorkingDirectory=/opt/yuyue/server
EnvironmentFile=/opt/yuyue/server.env
ExecStart=/opt/yuyue/server/bin/server
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable yuyue && sudo systemctl start yuyue
journalctl -u yuyue -f   # 查看日志
```

## Nginx 反向代理

```nginx
server {
    listen 443 ssl http2;
    server_name api.example.com;
    ssl_certificate     /etc/nginx/ssl/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

安全组：公网放行 **443**，**8080** 仅内网。

## Android 指向线上

修改 `android-app/build.gradle.kts`：

```kotlin
buildConfigField("String", "API_BASE_URL", "\"https://api.example.com\"")
```

Sync + 重新构建安装。Release 应关闭 `usesCleartextTraffic`。

## 数据库

1. 云控制台创建 PostgreSQL 14~16，与 ECS 同地域同 VPC
2. 执行 `server/migrations/V1__init.sql`
3. 开启 RDS 自动备份

## 环境变量速查

| 变量 | 本地 | 生产 |
|------|------|------|
| `PORT` | `8080` | `8080`（内网） |
| `DEV_MODE` | `true` | `false` |
| `JWT_SECRET` | 任意 | 强随机 |
| `DATABASE_URL` | H2 默认 | RDS 内网 JDBC |
| `LLM_API_KEY` | 可选（不设走 Mock） | 按需 |

## 生产必改项

- `DEV_MODE=false` — 关闭控制台 OTP
- `JWT_SECRET` — 强随机密钥
- 短信服务 — 对接云厂商 API
- HTTPS — 客户端只访问 `https://` 域名
- 密钥勿提交 Git
