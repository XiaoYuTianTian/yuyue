## 本地 Agent 切片

| ID | 任务 | 状态 | 主要位置 |
|----|------|------|----------|
| local-agent-vector | Room SoT + FTS/向量 + AgentLoop + UI 接线 | 已完成 | `android-app/.../agent/`、`data/ai/`、`data/local/`、`AppViewModel` |

能力摘要：

- 首次启动种子记事本（生活/工作），跳过短信登录
- 一段输入可拆成多条日程；同一天可有多条
- 回忆「去年某天做了什么」：本地解析日期 + `get_entries_by_day` / `get_entries_by_range`，结果按时间排序展示
- 工具：`list_notebooks` / `search_keyword` / `search_similar` / `get_entries_by_day` / `get_entries_by_range` / `get_entry` / `upsert_entries` / `mutate_entries` / `export_snapshot`
- Embedding：`embo-01`（MiniMax），向量存 `entry_embeddings`
- 设置页可改 API Key / Base URL / 模型（EncryptedSharedPreferences）

## 本地运行速查

1. 在根目录 `config.local.properties` 填写 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`（或 App 设置页填写）
2. Android Studio 运行 `android-app`（**无需**先启 `server`）
3. 语音写入 / 回忆会调用 MiniMax；日历断网仍可读本地数据
