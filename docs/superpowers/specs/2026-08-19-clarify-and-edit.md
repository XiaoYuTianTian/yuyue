# 语曰 · 不完整记录：少问、可跳过、事后能改

日期：2026-08-19  
状态：已锁定  

覆盖 8-17 中「没时间就用现在、clarify 不带 entries」的口径。

## 够不够（所有类型同一规则）

时间 / 地点 / 人物 三项，**缺 ≥ 2 项才追问**；只缺 1 项直接记下。

- 时间：用户没说日期或时刻则算缺（默认现在 **不算** 已说）
- 地点 / 人物：空则算缺
- 用户说「先记下」「不用补了」「以后再说/再补」→ 立刻入库
- 追问最多 **2 轮**；第 3 次开口一律入库
- 每轮只问 `missing_slots` 的第一项
- 每轮仍只调用一次 MiniMax

## JSON

`time_explicit`、`missing_slots`；`clarify` 必须带当前最好的 `entries` 草稿，客户端展示芯片，**先记下之前不写库**。

## UI

草稿卡：一句问 + 时间/地点/人物芯片 + 只读转写 + 「取消」「先记下」「记录」。
编辑页：标题、正文、日期时刻、地点、人物、类型、完成态、删除。
