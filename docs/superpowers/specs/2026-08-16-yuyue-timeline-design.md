# 语曰 · 一球三层轴

日期：2026-08-16  
状态：待你过目后再写实现计划  
做法：A · 打开即月历，一个底部按钮，点日期下钻到日轴和红绿胶囊

## 1. 产品一句话

说出口的事落到时间上：已经发生的留下来，将要做的先挂上。打开看月，点进看当天时段，问一句能沿线找回，并能跳回那天。

## 2. 已锁定口径

| 项 | 决定 |
|----|------|
| 时间范围 | 过去和未来都记 |
| 颜色 | 绿 = 已做（`done=true`），红 = 未做（`done=false`） |
| 已发生的事 | 一记下来就是绿 |
| 将做的事 | 先红；在展开后的胶囊或详情里改红绿，或再说「见完了」才变绿 |
| 时间走到 | 不自动变绿 |
| 写入 | 先预览（时刻、记事本、红绿），确认后才落库 |
| 日期 | 请求带上设备当前时间，由模型根据原话判断；判断不了则今天 |
| 记事本 | 生活 / 工作是种子，可扩展；口述可建本或挂本 |
| 入口 | 底部一个按钮管记、问、建本、删改；去掉顶部放大镜 |
| 浏览 | 月 → 日轴 → 胶囊 → 详情 |
| 数据 | 仍只在本机 Room |

不做（本设计范围外）：闹钟推送、云同步、原始录音、照片、多人共享。

## 3. 三层怎么看

**月**  
当前记事本的月历。有记录的日期打点：当天全是绿则绿点；有任何红则红点（未做优先看见）。左右换月。点日期进入日轴。标题旁是记事本选项卡（种子 + 自定义 + 加本）。设置齿轮保留。顶部搜索图标去掉。

**日轴**  
只渲染有记录的时段，不铺 24 个空小时。模糊时间（「晚上」）在轴上显示「约晚上」，详情里保留原话。

**胶囊**  
短标签 + 红/绿。点胶囊只展开关键内容，不直接改红绿。展开后可切红绿，或再点进详情。详情可改时刻、记事本、红绿，可删（软删进废纸篓）。

从日轴返回月历。回忆连线跳到某天时，打开的是同一套日轴，命中胶囊高亮。

## 4. 底部这一下

长按说话，点按打字。每次调用模型都带：

- 设备当前时间（含时区，ISO-8601）
- 用户原话
- 当前选中的记事本（可被模型改挂）
- 已有记事本列表（供建本 / 挂本）

意图四条路，仍由模型判断（客户端规则只做弱提示，不以关键词一锤定音）：

1. **记下**：拆成 1..N 条草稿 → 预览 → 确认后写入。
2. **问**：只检索，进入连线，不写。
3. **建本 / 挂本**：先本后条，仍走预览。
4. **删 / 不用了 / 见完了**：找到对应条，确认后软删、取消，或把 `done` 置 true。

预览里每条可见、可改：标题、时刻、记事本、红绿；可去掉单条。关掉预览则整批不写。没 Key、没网、没听清：不写，原文留在输入里可再送。

「撤掉刚才那批」按同一次说话的 `utteranceId` 软删，月历打点收回。

## 5. 问一句之后

问的时候同样带上当前时间，由模型定范围和问法。

| 问法 | 匹配 | 展开 |
|------|------|------|
| 定点 | 某天 / 某段时间 | 跳到那天的日轴，高亮命中胶囊 |
| 主题 | 同一 `subjectKey` | 按 `startAt` 连成一条线，胶囊标关键节点 |
| 次数 | 去过几次 | 数 `done=true` 的命中，并连线 |
| 未做 | 还有什么没做 | 只收 `done=false` |

点连线上的胶囊：看关键内容 → 可跳回那天的时段。站在那个点上可补记，补记仍走预览。

连线动画：按时间顺序把节点串起来即可，不做力导向图。回忆「我做了什么」只收绿色；「还有什么没做」只收红色。

过期仍未做的红条：留在原来的 `startAt` 那天，不挪到今天。月历上那天保持红点。

## 6. 数据

仍用现有 Room。新增字段，不做平行库。

**notebooks**（已有）  
开放增删改。种子 `life` / `work` 不可删，可改名改色。自定义本在没有未删条目时可删。

**entries**（已有）上新增：

| 字段 | 含义 |
|------|------|
| `done` | `true` 绿 / `false` 红。与 `status`（active / cancelled）分开 |
| `utteranceId` | 同一次说话拆出的多条共用；撤回整批用 |

沿用：

- `startAtMillis` / `endAtMillis`：轴上的落点
- `statedAtMillis`：说出口的时刻
- `subjectKey`：主题连线键（同一家店、同一个人、同一件事）。模型负责归一，不另建图谱表
- `rawTranscript`：原话
- 软删 `deletedAtMillis`、废纸篓

月历打点、日轴、回忆过滤都读 `done` + `startAt` + `notebookId` + 未删除。

向量表和 FTS 保持，供「相关」检索。

## 7. Agent 与数据流

记下：

```
原话 + now → 模型出草稿（不写库）→ 预览 → 用户确认
  → 需要时 upsert 记事本 → upsert_entries（带 done、utteranceId、subjectKey）
  → 刷新月历 / 若在日轴则刷新轴
```

问：

```
原话 + now → 模型选工具（按日 / 按段 / 关键词 / 相似 / 本列表）
  → 本地执行 → 按问法过滤 done → 连线 UI
```

标已做 / 删除：模型指出 id，客户端确认后改 `done` 或软删。

工具：

- 保留：`list_notebooks`、`search_keyword`、`search_similar`、`get_entries_by_day`、`get_entries_by_range`、`get_entry`、`upsert_entries`、`mutate_entries`、`export_snapshot`
- 新增：`upsert_notebook`（建/改）、`delete_notebook`（仅空的自定义本）、`set_entry_done`
- `upsert_entries` 增加 `done`、`utteranceId`；未带 `done` 时：`startAt` 早于 now 则 true，否则 false
- 记下路径禁止在预览确认前调用写入类工具。实现上用「propose 模式」：第一轮只返回 JSON 草稿给 UI

## 8. 对现有界面的改动

| 现在 | 改为 |
|------|------|
| 生活/工作写死分段 | 可滚动选项卡 + 加本 |
| 顶部搜索 → 独立回忆页 | 去掉图标；问从底部进，连线盖在月/日之上 |
| 日详情 = 卡片列表 Sheet | 日轴 + 胶囊 |
| 写入直接 upsert | `IngestPreviewSheet` 接入真路径（时刻、本、红绿） |
| 无 `done` | 条目、胶囊、月历点都读 `done` |

## 9. 实现切片（计划阶段再拆任务）

本设计大于一次改动，实现时按切片，不一次做完：

1. 数据：`done`、`utteranceId`；记事本增删改；种子不可删
2. 预览接入 + 请求带 now；写入必须确认
3. 日轴 + 红绿胶囊 + 月历红/绿点；去掉搜索图标
4. 问：按 `done` / `subjectKey` 连线、跳轴、可补记
5. 建本/挂本走预览；「见完了」和整批撤回

## 10. 验收

- 说「昨晚那家店很好吃」：预览落在昨天晚上、绿色；确认后昨天绿点
- 说「明天下午三点见客户」：预览明天 15:00、红色；过了明天仍红，直到标已做
- 一次说两件：预览两条，去掉一条则只写留下的
- 说「帮我开一个吃饭收藏并记下刚才那家店」：预览出现新本 + 一条绿
- 说「那家店去过几次」：只数绿色，连线可跳回对应日轴
- 说「还有什么没做」：只出现红
- 关掉预览：库里没有新条
- 无网 / 无 Key：不写，输入还在

## 12. 完整 App 里有哪些页

没有登录墙（本地模式）。信息架构只有这些：

```
打开 → 月
         ├─ 日轴 → 胶囊展开 → 详情
         ├─ 按住 / 点按 → 预览 → 回月或日轴
         ├─ 问 → 跨日连线 → 跳回某日轴
         └─ 我 → 声音与模型 / 数据 / 关于
                    └─ 废纸篓
```

**打开**  
大字「语曰」，没有搜索。记事本是一行芯片。月历很空。底下只有球。右上是「我」（头像），不是齿轮。

**按住说话**  
球放大，原文实时出现在球上方。松手出预览。没有第二套输入页。

**先看一眼**  
每条一张卡：苔/陶边、时刻、本、红绿、标题。可改、可去掉。主按钮「记下」，次按钮「先不写」。

**记下之后**  
若落点是今天：留在日轴，新胶囊在对应时段。若是别的天：回到月，那天打点，轻提示「记在 8月15日」。

**跨日问到之后**  
不是搜索列表。上方是原问 + 一句短答（「3 次 · 都在生活」）。中间是按时间串起来的节点。点节点回那天日轴并高亮。球还在，可以当场补记。

## 13. 「我」和用户属性

语曰没有账号体系。用户属性只存在本机，给模型和默认落本用。

| 字段 | 必填 | 用途 |
|------|------|------|
| `displayName` | 否 | 「我」页怎么称呼；模型回称 |
| `addressAs` | 否，默认「你」 | 模型对用户的称呼 |
| `tone` | 否，默认「轻松」 | 预览标题和回忆短答的口气：轻松 / 克制 |
| `defaultNotebookId` | 是，默认生活 | 没说挂哪本时 |
| `avatarUri` | 否 | 本地图片，不上传 |

设置只分四块，不做成系统设置克隆：

1. **我** — 上面这些属性 + 默认本
2. **声音与模型** — 系统语音、API Key、模型（折起来，不占首页）
3. **数据** — 导出 JSON、废纸篓、清空本机（二次确认）
4. **关于** — 一句话产品 + 版本

首版不做：深色模式、账号、生日、性别、兴趣标签。语气和称呼已经够模型「像在跟这个人说话」。

实现切片第 0 步改为：先换纸面视觉（色、字、球、去搜索），再按原 1–5 切片加能力。
