## 1. 产品一句话

打开语曰，先看到问候和「接下来 / 近来」的混合流；月历是进去看的详情，不是大门。

## 2. 已锁定

| 项 | 决定 |
|----|------|
| 根界面 | **每次冷启动都是欢迎页**，不是一次性引导 |
| 进月历 | 顶栏 **「月历」** |
| 进某日 | 点欢迎页一条 → 该条 `startAt` 所在日的时间线（不经月历） |
| 返回 | 按栈：日页回到来源（欢迎或月历）；月历回到欢迎 |
| 混合流 | 未来未完成 ∪ 近 12 条，去重后按 `startAt` 降序，最多 24 |
| 行样式 | 短日期（今天/明天/`M月d日`）+ `HH:mm` + 标题 + 红/绿点 |
| 空态 | 「还没有要做的事。按住下方，记下第一句。」 |
| 语音球 | 欢迎、月历、日时间线都保留 |
| 记事本 | 只在欢迎页切换；月历沿用当前本 |
| 视觉 | Navy / Signal / Warn；草稿只读不弹键盘 |

不做：TTS、独立检索大页、欢迎页滑动删除、首次安装动画。

## 3. 信息架构

```
欢迎页（根）+ 底部语音
  ├─ 顶栏「月历」 ──────────► 月历页
  │                            ├─ 点日期 ──► 日时间线 ──► 详情
  │                            └─ 返回欢迎
  ├─ 点一条 ─────────────────► 日时间线 ──► 详情（返回欢迎）
  ├─ 设置 ───────────────────► 设置 / 回收站
  ├─ 记录成功 ──► 3 秒标题弹窗 ──► 刷新欢迎流
  └─ 检索 ──────► 当前页结果卡
```

---

## 4. 混合流规则

当前记事本、未删除、`status=active`：

1. 纳入全部 `done == false` 且 `startAtMillis > now`。
2. 并入按 `startAtMillis` 倒序最近 12 条。
3. 按 `id` 去重；若超过 24 条：优先保留未来未完成，再用近记补齐，最后整体按 `startAtMillis` 降序。
