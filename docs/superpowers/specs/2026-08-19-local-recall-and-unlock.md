## 1. 日期解锁

`recall_query.time_from` / `time_to` 表示**同一天**（含 `to` 为次日 0 点的半开区间）时：

- 直接打开该日时间线（栈上推进 `Day`）。
- 不弹结果卡；日页自己列出条目。空日也打开（「这一天还没有记录」）。

跨多天：不解锁，走结果卡。

## 2. 语义找回

本机 **BGE-small-zh-v1.5** ONNX（量化）+ `vocab.txt`。写入后 FTS 立即建、向量后台建。检索：

1. 有单日 → 解锁。
2. 否则：有 keyword / title_hint 时做 FTS/LIKE 结构化命中（标题精确 1.0，其余 0.85）；**仅有时间窗、无关键词时不倒库**，时间只约束语义窗口。
3. 用用户原话做 query 向量，与结构化命中一并过置信度门槛：
   - 绝对下限余弦 **≥ 0.52**
   - 相对带：只保留 `score ≥ max(0.52, best − 0.08)`
   - 结果按 **score 降序**（同分再按时间），卡上限 8
4. 过门槛为空 → **追问**（有无时间窗都追问），不甩弱相关列表：
   - 无时间无关键词：问年份/人物
   - 无时间：问大概时候
   - 有时间无关键词：问关键词/标题/人物
   - 都有仍空：问更具体标题或关键词
5. 多轮追问上限 **3**；仍无高匹配 →「没有找到相近的日记，可以换个说法或新记一笔」，结束本轮。
